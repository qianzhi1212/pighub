# PigHub · 猪猪收藏馆

使用 16 张现有原图的轻量网页，支持搜索、分类、浏览器本地收藏、随机抽猪、原图下载，以及 20 道原创情境题的猪猪性格匹配。

性格结果包含四组偏好、对应理由、长处提醒与趣味搭子推荐。题目参考 MBTI 四组偏好编写，非官方测评，猪猪映射与搭子推荐为网站设定。

## 打开

`index.html` 是完整的单文件网页，可以直接双击离线打开。全部样式、交互和原始 JPEG 字节都嵌在其中，无外部依赖。

## GitHub Pages

在仓库的 Settings → Pages 中选择 Deploy from a branch，再选择 main 和 /(root)，保存后等待 GitHub 显示发布成功与网站地址。

`.nojekyll` 用于按普通静态文件发布。今后更新 `index.html` 即可更新网站。

在线链接可以分享图片与测试结果；离线版可下载原图后分享。收藏保存在当前浏览器中。
