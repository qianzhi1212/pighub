# PigHub · 猪猪性格测评与图鉴

[打开网站](https://qianzhi1212.github.io/pighub/)

首页聚焦「测评」与「图鉴」。20 道原创生活情境题，匹配 16 种猪猪性格，提供性格分析、四组偏好和趣味合拍搭子。

## 历史记录

完成测评会自动保存结果。在首页或结果页点击「历史记录」，可按保存时间重新查看最近 30 条结果，包括原来的小猪、四组偏好、性格分析与搭子。重复查看不会新建记录，记录列表不加载图片。

记录保存在当前浏览器，刷新或再次打开仍可查看，不跨设备或浏览器同步；清理网站数据会清除记录。浏览器不允许保存时，页面会提示记录仅在本次打开有效。

旧版本没有保存历史，无法自动补回。若保留了完整结果链接（包含类型及四组偏好），打开后可点击「保存到历史记录」手动补存，记录显示本次保存的时间。

## 图片与加载

- 首页和答题过程不请求任何图片，文字与按钮先可用。
- 结果页只加载对应的一张原图，搭子图片在打开详情时加载。
- 图鉴每次展示 4 只，从较小的原图开始；只在图片进入视口后请求。
- 全部 16 张 JPG 保持原始文件名和字节，未压缩、裁剪、重绘或替换。
- 首页 HTML 约 50 KB，不依赖第三方脚本或字体。

点击图鉴卡片可阅读性格分析、查看搭子或保存原图。

## 本地开发与发布

源码在本地项目的 `src/`；`assets/` 保存 16 张原始 JPG。

- `python build.py --pages`：生成在线版 `pages/`。发布时将该目录的 HTML、JPG 和 `.nojekyll` 放在同一目录。
- `python build.py`：生成内嵌全部原图的离线单文件 `dist/index.html`。在线发布使用独立图片版本。
- `node test_ui.cjs http://127.0.0.1:8726/pages/`：检查完整测评、16 类结果、搭子、分享链接、历史保存与重开、旧结果补存、原图下载、图鉴分页和手机布局。

GitHub Pages 使用 main 分支的根目录。更新网页时替换 `index.html`，保留 16 张 JPG。

## 题目与性格设定

参考 MBTI 的 E/I、S/N、T/F、J/P 四组偏好编写原创情境题，未使用官方测评题库。每组 5 题，交错呈现，选项采用 ±3、±1 分，部分反向计分。条形比例只表示这次回答的偏向。

16 个类型分别对应一张现有原图。搭子设定保持 S/N、T/F、J/P 相同、切换 E/I，意在表达理解方式同频、社交方式互补；这是一项趣味规则。

非官方测评，结果不作为专业心理判断或现实关系配对结论。

参考：[四组偏好](https://www.myersbriggs.org/my-mbti-personality-type/the-mbti-preferences/)、[类型与相处](https://www.myersbriggs.org/type-in-my-life/personality-type-and-relationships/home.htm)。
